# Book Finder — Nine User Stories

1. As a visitor, I want to create an account with my name, email, and password so I can save books.
2. As a returning user, I want to log in with my email and password so I can access my reading list.
3. As a reader, I want to see a home screen with book recommendations so I can discover books quickly.
4. As a reader, I want to search an external book API so I can find titles by name or author.
5. As a reader, I want to open a book detail screen so I can see its author and publication year.
6. As a reader, I want to save and remove favorites so I can keep a personal reading list.
7. As a reader, I want favorites and account details to persist in my browser so my data is available when I return.
8. As a reader, I want a settings menu and settings screen so I can manage my profile and preferences.
9. As a reader, I want browser notifications so I can receive a reading-list reminder.
